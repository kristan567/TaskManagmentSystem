# 📝 Task Management System

A full-stack Task Management System built with **Node.js (Express)** for the backend and **React** for the frontend. This project allows users to manage tasks with status updates, and is built using a modular and scalable architecture.

---

## 📁 Project Structure

Task-management-system/ ├── client/ # Frontend (React) 
                        ├── server/ # Backend (Express + MongoDB)
                        ├── .gitignore
                        ├── README.md
                          └── .env.example # Environment variable template




---

## 🚀 Features

- Create, Read, Update, Delete (CRUD) tasks
- Task statuses: `pending`, `in-progress`, `completed`
- RESTful API design
- MongoDB with Mongoose ODM
- Toast notifications for UX feedback
- Axios for HTTP requests
- React Router for navigation and routing
